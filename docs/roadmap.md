# План работ

Принцип: один шаг за раз. У каждого шага есть критерий готовности. Шаг закрывается только после проверки.

## Этап 1. Перенос на Python и сверка с pandapower
- [ ] 1.1 Python-пакет `twin/`: модель сети (данные — в отдельном файле `data/network.yaml`, не в коде).
- [ ] 1.2 Расчёт режима через pandapower для той же условной схемы.
- [ ] 1.3 Сверка pandapower ↔ текущее JS-ядро на 400 сценариях. **Готово, если** |ΔU| < 1e-4 о.е., ΔP < 0,01 МВт.
- [ ] 1.4 Автотесты (pytest), запуск проверок одной командой.

## Этап 2. Реальные данные
- [ ] 2.1 Погода: архив и прогноз Open-Meteo для Актау, Жанаозена, Бейнеу.
- [ ] 2.2 Схема сети из открытых источников (OpenStreetMap, отчёты KEGOC/МРЭК). Каждое значение помечено: *источник* или *допущение*.
- [ ] 2.3 Нагрузка: реальные данные, если удастся получить; иначе обоснованные диапазоны со ссылками.
- [ ] 2.4 Трансформаторы 220/110 и 110/35/10 кВ на подстанциях.

## Этап 3. Модель и физика

- [ ] 3.3 DLR: параметры конкретных линий, направление ветра по участкам.

## Этап 4. Эксперименты для научной работы
