# Правила работы над проектом

- Общение и комментарии в коде — на русском.
- Работаем по шагам из `docs/roadmap.md`: сначала план шага, изменения — только после одобрения.
- Перед завершением шага обязательно запускать проверки из `validation/` (и pytest, когда появится).
  Шаг не считается готовым, если проверки не проходят.
- Каждое значение параметров сети помечается как *источник* (со ссылкой) или *допущение*.
  Не выдавать допущения за реальные данные.
- После шага — запись в `docs/decisions.md`: что сделано, чем проверено, что не получилось.
- Неудачные результаты не скрывать: они нужны для научной работы.
